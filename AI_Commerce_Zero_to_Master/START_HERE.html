11. Troubleshooting checklist

ProblemCheck
Java will not startjava -version, mvn -version, port 8080, then mvn test.
Python import errorActivate ai-python/.venv, reinstall requirements.txt, run python -m pytest -q.
Ollama unavailableollama list, verify model exists and port 11434 is listening.
Vector DB failureStart data compose; verify 6333 for Qdrant or 5432 for pgvector.
Prometheus / learning site collisionKeep Prometheus on 9090 and run learning site on 9100.
Docker stack does not startRun docker compose ... config, inspect port conflicts and Docker Desktop/WSL health.
Mock data validation failsRegenerate with fixed seed and --reset, then run validator.
Payment retry creates duplicatesInspect checkout idempotency key and payment intent mapping.
Wrong AI answerSeparate retrieval failure, tool failure, routing failure and generation failure.
Debug order: infrastructure → process/port → API → data/schema → model/tool → orchestration → UI. Test the smallest failing layer first.

Single-click Docker local deployment

Auto mode: double-click START_LOCAL_DOCKER.bat or START_FULL_LOCAL_DOCKER.bat. The launcher tries preferred ports first and automatically moves to another free host port when needed.

Interactive mode: use the interactive launchers when you want to approve or type each host port yourself. Occupied and duplicate ports are rejected before Docker starts.
